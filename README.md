# Conversando por Voz com o ChatGPT utilizando Whisper e Python

Converse com o ChatGPT utilizando apenas a sua voz. Este projeto demonstra como integrar os modelos da OpenAI para criar uma interação por linguagem natural, convertendo fala em texto, processando a solicitação com o ChatGPT e retornando a resposta em áudio.

> **Observação:** É necessário possuir uma **chave de API da OpenAI** para executar o projeto.

---

## Funcionalidades:

* Captura da voz do usuário.
* Transcrição automática da fala utilizando o **Whisper**.
* Processamento da solicitação com o **ChatGPT**.
* Conversão da resposta em áudio.
* Interação em linguagem natural sem necessidade de escrever comandos.

---

## Tecnologias utilizadas:

* Python
* OpenAI API
* Whisper
* Google Colab

---

## Como executar:

1. Obtenha uma chave de API da OpenAI.
2. Abra o notebook no Google Colab.
3. Configure sua chave de API.
4. Execute as células do notebook.
5. Grave sua pergunta utilizando o microfone.
6. Aguarde a resposta gerada pelo ChatGPT.
